Conversion Optimization Through A/B Testing

📸 View Dashboard 🌐 GitHub

Analyzed 290K+ user experiment records using Python, SQL, BigQuery, and statistical testing to evaluate whether a new website experience improved conversion rates.

Key Insights

  • Cleaned and validated 290,587 experiment records, checking missing values, duplicates, repeated users, and experiment-group consistency.
  • Compared Control vs Treatment conversion rates and calculated the observed conversion difference and relative lift.
  • Performed power analysis, confirming the experiment had sufficient sample size to detect the targeted improvement.
  • Conducted a two-proportion z-test and found a p-value of 0.0946, indicating no statistically significant evidence that the Treatment experience improved conversion.
  • Calculated a 95% confidence interval of -0.394% to +0.078%, which included zero and reinforced the conclusion.
  • Explored experimentation risks including peeking, A/A testing, multiple-testing considerations, and guardrail metrics.
  • Built an interactive Looker Studio dashboard to communicate the experiment results.

Technologies: Python, Pandas, NumPy, SQL, Google BigQuery, Statsmodels, Matplotlib, Looker Studio, Statistical Analysis

Impact & Insights: Determined that the new website experience did not produce statistically significant conversion improvement, providing a data-driven basis for avoiding an unsupported rollout and informing future experimentation.

Customer Satisfaction Analysis in Brazilian E-Commerce (Olist)

📸 View Dashboard 🌐 GitHub

Analyzed 99,000+ e-commerce orders across 7 relational datasets using Python and SQL to uncover the key drivers of customer satisfaction and translate them into an interactive Tableau dashboard.

Key Insights

  • Merged and cleaned 7 relational datasets (~99K orders) using Python/Pandas to build a unified analysis base.
  • Ran Pearson correlation testing to quantify the link between delivery delay and review score (r = -0.27, p < 0.001).
  • Found 1-star orders were delivered ~9 days later on average than 5-star orders, confirming delivery speed as a satisfaction driver.
  • Identified underperforming product categories (lowest-rated: 2.5/5 vs. platform mean 4.09/5) and a 0.6-point satisfaction gap between top and bottom-performing states.
  • Built an interactive Tableau dashboard to communicate findings to non-technical stakeholders.

Technologies: Python, Pandas, SQL, Tableau, Statistics (Pearson correlation)

Impact & Insights: Identified delivery delay as a statistically significant driver of poor reviews, alongside category- and region-level satisfaction gaps — providing a data-backed basis for prioritizing logistics and regional service improvements.
