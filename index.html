📦 Customer Satisfaction Analysis in Brazilian E-Commerce (Olist)

📸 View Dashboard 🌐 GitHub

Analyzed 99,000+ e-commerce orders across 7 relational datasets using Python and SQL to uncover the key drivers of customer satisfaction and translate them into an interactive Tableau dashboard.

Key Insights

  • Merged and cleaned 7 relational datasets (~99K orders) using Python/Pandas to build a unified analysis base.
  • Ran Pearson correlation testing to quantify the link between delivery delay and review score (r = -0.27, p < 0.001).
  • Found 1-star orders were delivered ~9 days later on average than 5-star orders, confirming delivery speed as a satisfaction driver.
  • Identified underperforming product categories (lowest-rated: 2.5/5 vs. platform mean 4.09/5) and a 0.6-point satisfaction gap between top and bottom-performing states.
  • Built an interactive Tableau dashboard to communicate findings to non-technical stakeholders.

Technologies: Python, Pandas, SQL, Tableau, Statistics (Pearson correlation)

Impact & Insights: Identified delivery delay as a statistically significant driver of poor reviews, alongside category- and region-level satisfaction gaps — providing a data-backed basis for prioritizing logistics and regional service improvements.

📉 Customer Churn Prediction & Retention Analytics

📄 Live App 🌐 GitHub

Built a churn prediction model on 7,000+ telecom customer records and simulated the financial impact of a targeted retention strategy, deployed as an interactive Streamlit app.

Key Insights

  • Built and trained a Logistic Regression model to predict customer churn, achieving 78.7% accuracy on a held-out test set.
  • Ranked customers by predicted churn probability to identify the top 20% highest-risk segment for retention outreach.
  • Modeled the financial tradeoff between a targeted retention campaign and blanket discounting.
  • Projected a net profit of $22,380 against a $5,620 campaign cost when targeting high-risk customers specifically.
  • Deployed the full analysis as an interactive Streamlit app for real-time exploration.

Technologies: Python, Scikit-learn, SQL, Streamlit

Impact & Insights: Demonstrated that targeting high-risk customers with retention offers is significantly more cost-effective than broad discounting, providing a data-driven framework for retention budget allocation.
